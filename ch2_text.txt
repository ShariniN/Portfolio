Index 25 (Normal): 1.2 Background / Problem Domain
Index 26 (Normal): Financial fraud is one of the most costly and rapidly evolving threats facing global banking systems. According to the Association of Certified Fraud Examiners, organisations lose an estimated 5% of annual revenue to fraud, with financial institutions disproportionately affected. Modern fraud detection systems are required to operate in real-time across billions of transactions, making false negatives — missed fraudulent transactions — financially and reputationally catastrophic.
Index 27 (Normal): Traditional centralised fraud detection, in which all transaction data is pooled into a single model, is increasingly untenable in regulated financial environments. Regulations such as the General Data Protection Regulation (GDPR) and the Payment Card Industry Data Security Standard (PCI-DSS) impose strict constraints on cross-institutional data sharing, preventing banks from collaboratively training fraud models on raw transaction records.
Index 28 (Normal): Federated Learning (FL) offers a principled solution to this conflict: instead of sharing raw data, each participating institution trains a local model on its own data and shares only model updates — gradients or weights — with a central aggregation server. The global model benefits from all participants' patterns without any raw data leaving individual institutions. However, FL alone does not provide formal privacy guarantees; a sophisticated adversary observing shared gradient updates can perform gradient inversion attacks or membership inference attacks to reconstruct sensitive transaction data.
Index 29 (Normal): Differential Privacy (DP) is the gold standard for formal privacy guarantees. When applied to FL via the DP-SGD mechanism, it adds calibrated Gaussian noise to each client's gradient before sharing, bounding the privacy loss (epsilon, delta) across training rounds. However, a critical and unresolved tension exists: uniform DP noise addition is most damaging to the borderline, high-uncertainty transactions that are most important for fraud detection. These are the transactions that do not clearly belong to either the fraudulent or legitimate class — the grey zone where fraud is hardest to detect and most costly to miss. Existing FL+DP systems apply identical noise to all transactions regardless of their classification difficulty, systematically degrading performance on precisely these most critical cases.
Index 30 (Normal): This project addresses this gap by developing a hierarchical, uncertainty-aware adaptive DP mechanism that leverages Conformal Prediction (CP) scores to modulate noise at two levels: per-sample (adjusting noise inversely to uncertainty) and per-client (weighting client contributions by their aggregate uncertainty). This dual-level adaptation, combined with the application to the banking fraud detection domain, constitutes the core novel contribution of this research.

Index 37 (Normal): 1.5 Research Gap
Index 38 (Normal): Gap 1 — No uncertainty-driven DP adaptation at the sample level in fraud detection: All existing FL+DP fraud detection systems (FraudNetX 2025, HAPB-FL 2025) apply uniform DP noise to all training samples regardless of classification difficulty. Uniform noise disproportionately destroys signal on borderline fraud cases — precisely those with the highest detection value. No existing mechanism uses prediction uncertainty as a signal to selectively reduce noise where it causes the most harm.
Index 39 (Normal): Gap 2 — No hierarchical two-tier adaptive DP framework: Existing adaptive DP papers (HAPB-FL, Edge Dynamic Budget 2025) address either sample-level or client-level adaptation, never both simultaneously. A hierarchical framework that adapts DP noise both within each client (per-sample) and across clients (per-client aggregation weighting) based on uncertainty does not exist in the current literature.
Index 40 (Normal): Gap 3 — No convergence of conformal prediction, federated learning, and differential privacy in the banking fraud domain: FCP-Pro provides CP in FL without DP; DPCP provides CP with DP but without FL or fraud application; VAE-QLSTM FL provides FL for fraud without DP or CP. No single system unifies all three in the fraud detection context, leaving a clear and significant gap this project fills.

Index 46 (Normal): 1.7 Research Challenges
Index 47 (Normal): Challenge 1 — Formal Privacy Accounting Under Adaptive Noise: Standard Renyi Differential Privacy (RDP) accountants assume a fixed noise multiplier across all samples. When noise is sample-adaptive, the privacy accounting becomes non-trivial. Existing per-instance DP (pDP) frameworks offer partial solutions (Dong et al. 2022) but have not been applied to tabular fraud data. A conservative bounding strategy must be derived and validated to ensure the claimed epsilon guarantee remains formally correct.
Index 48 (Normal): Challenge 2 — Conformal Coverage Under Non-IID Distribution: Conformal prediction's marginal coverage guarantee assumes i.i.d. calibration and test data. In a federated setting with non-IID partitioning (Dirichlet alpha = 0.1), each client's calibration set distribution differs from the global test distribution, threatening the validity of the coverage guarantee. Weighted conformal prediction (Tibshirani et al. 2019) or federated calibration reweighting must be implemented to restore valid coverage.
Index 49 (Normal): Challenge 3 — Severe Class Imbalance Interaction with DP Noise: The IEEE-CIS dataset has a fraud rate of approximately 3.5%, while the European Credit Card dataset has a rate of only 0.172%. DP noise already disproportionately degrades minority class signal; combining this with class imbalance creates compounded degradation on fraud detection. Borderline-SMOTE and class-weighted loss must be carefully integrated at each client without violating the federated architecture or the DP guarantee.
Index 50 (Normal): 1.8 Research Questions
Index 51 (Normal): RQ1: To what extent does conformal prediction-based, per-sample adaptive differential privacy noise modulation improve recall on borderline fraud cases compared to uniform DP-FedAvg at matched privacy budgets (epsilon = 1, 3, 5, 10)?
Index 52 (Normal): RQ2: How does uncertainty-weighted client aggregation — where clients with lower average conformal uncertainty receive higher aggregation weight — affect global model performance and robustness under non-IID data distributions (Dirichlet alpha = 0.1, 0.5, 1.0)?
Index 53 (Normal): RQ3: What is the formal privacy accounting correction required to maintain a valid (epsilon, delta)-DP guarantee when the DP-SGD noise multiplier is sample-adaptive, and how does this correction affect the empirical privacy-utility tradeoff curve?
Index 54 (Normal): RQ4: How does the proposed hierarchical adaptive DP framework compare to existing baselines — DP-FedAvg, HAPB-FL, and FCP-Pro — across utility (AUC-PR, Recall on fraud class), privacy (MIA success rate), and uncertainty calibration (conformal coverage) metrics on the IEEE-CIS and European Credit Card datasets?
Index 55 (Normal): 1.9 Research Aim
Index 56 (Normal): To design, implement, and empirically validate a hierarchical adaptive differential privacy framework for federated banking fraud detection that uses conformal prediction-based uncertainty quantification to modulate per-sample DP noise and per-client aggregation weights, thereby improving fraud recall on borderline transactions without violating formal (epsilon, delta)-DP privacy guarantees.

Index 71 (Normal): 2.3 Thematic Review
Index 72 (Normal): 2.3.1 Problem Domain: Federated Banking Fraud Detection
Index 73 (Normal): Banking fraud detection presents unique challenges for machine learning systems: extreme class imbalance (fraud rates as low as 0.172% on the European Credit Card dataset), evolving fraud patterns demanding online adaptability, and strict regulatory constraints preventing raw data sharing across institutions. Federated learning has emerged as the dominant privacy-preserving paradigm for multi-institutional financial modelling (R. et al., 2025, Sensors). However, the literature consistently demonstrates that standard FedAvg without privacy mechanisms is insufficient for regulatory compliance, and that naive addition of DP to FL causes disproportionate degradation of minority class recall.
Index 74 (Normal): Gahi (2025) represents the state of the art in applying FL to banking fraud, combining quantum-enhanced LSTM with variational autoencoders (VAE-QLSTM) evaluated on IEEE-CIS and European Credit Card datasets. While architecturally innovative, this work explicitly acknowledges the absence of formal differential privacy — a critical deployability gap under GDPR Article 25 (data protection by design) and PCI-DSS Requirement 3. This gap directly motivates the present research.
Index 75 (Normal): The IEEE-CIS Fraud Detection dataset (Vesta Corporation, 2019), consisting of 590,540 transactions with a 3.5% fraud rate and 394+ features, has been established as the de facto benchmark for federated fraud detection. A Springer 2025 comparative review of twelve peer-reviewed studies confirms this benchmark status and reports that the combination of Borderline-SMOTE, PCA dimensionality reduction, and ensemble models achieves state-of-the-art AUC-ROC of 0.918 in the centralised setting, providing a theoretical upper bound for the federated evaluation.
Index 76 (Normal): 2.3.2 Technological Review
Index 77 (Normal): Federated Learning Architecture: The canonical Federated Averaging (FedAvg) algorithm (McMahan et al., 2017) enables N clients to collaboratively train a global model by sharing gradient updates rather than raw data. However, FedAvg alone provides no formal privacy guarantee. Gradient inversion attacks (DLG, Zhu et al. 2019; iDLG) demonstrate that gradient tensors can be used to reconstruct original training samples with high fidelity, particularly for small batch sizes — a real vulnerability in banking contexts.
Index 78 (Normal): Differential Privacy in Federated Learning: DP-SGD (Abadi et al., 2016) addresses gradient inversion by clipping per-sample gradients at norm C and adding Gaussian noise N(0, sigma^2 C^2 I) before aggregation. Privacy loss is tracked via the Renyi Differential Privacy (RDP) accountant (Mironov, 2017) or the newer f-DP framework (Dong et al., 2022). The fundamental trade-off is that larger noise (lower epsilon, stronger privacy) degrades model utility, and this degradation is disproportionate for minority classes. HAPB-FL (Liu & Zhang, 2025) addresses this by adapting noise based on gradient sensitivity across clients, but makes no adaptation at the sample level and does not consider prediction uncertainty as a signal.
Index 79 (Normal): Conformal Prediction for Uncertainty Quantification: Conformal prediction (Vovk et al., 2005) is a distribution-free framework for constructing valid prediction sets with guaranteed marginal coverage. Given a significance level alpha, the conformal predictor guarantees that the true label is contained within the prediction set with probability at least 1-alpha, under the exchangeability assumption. The non-conformity score — typically 1 minus the softmax probability of the true class — provides a per-sample measure of prediction difficulty. Regularised Adaptive Prediction Sets (RAPS) extend this to produce well-calibrated adaptive sets. FCP-Pro (Li et al., 2025) demonstrates the feasibility of conformal prediction in federated settings, though without privacy integration. Wu et al. (2026) in DPCP demonstrate that DP and CP can be formally combined, but only in a centralised setting and using CP as an output wrapper rather than an input signal to the privacy mechanism.
Index 80 (Normal): Class Imbalance Handling Under Privacy Constraints: Standard SMOTE applied locally at FL clients is the most common imbalance mitigation strategy in the literature (IEEE-CIS comparative review, Springer 2025). However, Borderline-SMOTE offers a critical advantage: it specifically oversamples samples near the decision boundary — exactly those with high conformal uncertainty scores — creating a direct algorithmic alignment with the proposed adaptive noise mechanism. Synthetic data generated by Borderline-SMOTE is applied only to the local training set, preserving the federated architecture, and does not interact with DP noise applied to gradients.

AUC-PR directly reflects precision-recall trade-offs on the fraud class and is the correct metric for the stated objective of improving detection on borderline cases.

Index 96 (Normal): 3.2 Research Methodology
Index 97 (Normal): This research is positioned using Saunders' Research Onion across its six layers:
Index 98 (Normal): Philosophy — Positivism: This research adopts a positivist philosophy, treating privacy-utility trade-offs as objectively measurable phenomena. Formal mathematical definitions of differential privacy (epsilon, delta), empirical metrics (AUC-PR, F1, MIA AUC), and statistical significance tests provide objective, reproducible evidence. The hypothesis — that uncertainty-adaptive DP improves fraud recall without weakening privacy — is tested through controlled computational experiments rather than subjective interpretation.
Index 99 (Normal): Approach — Deductive: The research proceeds deductively: formal theoretical properties of DP and conformal prediction are used to derive the adaptive noise mechanism (Component 1) and uncertainty-weighted aggregation (Component 2), and these are then tested empirically against predictions from the theory (e.g., conformal coverage should be maintained at the target level; MIA success rate should remain near 50%).
Index 100 (Normal): Methodological Choice — Mono-method (Quantitative): All evaluation is quantitative, relying on computational experiments on public datasets. No qualitative data collection (interviews, surveys) is required. The mono-method choice is appropriate because the research questions are empirically answerable through metric comparison across controlled experimental conditions.
Index 101 (Normal): Strategy — Computational Experiment: The primary research strategy is controlled computational experiment. The IEEE-CIS dataset is partitioned into federated client environments under varying Dirichlet distributions (alpha = 0.1, 0.5, 1.0), and the proposed system is evaluated against baselines under matched privacy budgets. This is a controlled laboratory simulation, analogous to a scientific experiment, with all confounding variables (random seeds, model architecture, preprocessing pipeline) held constant across conditions.
Index 102 (Normal): Time Horizon — Cross-sectional: The evaluation is cross-sectional — all experimental conditions are measured at the completion of training (100 federated rounds), not tracked longitudinally. The focus is on the final model's performance, not its evolution over time, though training curves are reported for convergence comparison.
Index 103 (Normal): Data Collection and Analysis: The IEEE-CIS dataset (590,540 transactions, publicly available on Kaggle under competition license) and European Credit Card dataset (284,807 transactions, ULB, public) are used. No human participants are involved. Analysis methods include: Wilcoxon signed-rank tests for statistical significance; Renyi DP accountant for privacy budget tracking; LiRA for membership inference; iDLG for gradient inversion; MAPIE library for conformal calibration.
Index 104 (Normal): 3.3 Development Methodology
Index 105 (Normal): Iterative Prototyping is adopted as the development methodology. The project proceeds through four prototype cycles: (1) baseline DP-FedAvg implementation and evaluation; (2) integration of conformal prediction calibration pipeline; (3) per-sample adaptive noise mechanism (Component 1); (4) uncertainty-weighted client aggregation (Component 2). Each cycle produces a testable artefact against which metrics are measured, enabling incremental validation of each novel component.
Index 106 (Normal): Traditional waterfall methodology is explicitly avoided. The research nature of this project requires empirical feedback from each component implementation to inform the design of the next. Prototype evaluation at each cycle may necessitate adjustments to hyperparameters (noise multiplier scaling function, uncertainty threshold), which are incompatible with a fixed waterfall sequence.

Index 108 (Normal): The solution methodology follows a six-stage ML pipeline, adapted for the federated and privacy-preserving context:
Index 109 (Normal): Dataset Selection
Index 110 (Normal): 
Index 111 (Normal): Preprocessing and Feature Engineering: The following preprocessing pipeline is applied at each federated client locally (no cross-client communication required): (i) Missing value imputation using median imputation for continuous features; (ii) Yeo-Johnson Power Transform applied to TransactionAmt and V-columns to normalise skewed distributions (preferred over Box-Cox as it handles zero and negative values); (iii) StandardScaler normalisation — mandatory for DP-SGD, as unscaled features produce wildly varying gradient magnitudes that undermine the uniform clipping bound; (iv) PCA dimensionality reduction retaining 72 components (95% variance explained), fitted on a public validation fold — this directly reduces DP noise requirements since noise magnitude scales with the square root of dimensionality; (v) Target encoding for categorical features (card1-6, email domains) computed on the public validation fold only to prevent leakage; (vi) Borderline-SMOTE applied to the local training set only at a ratio of 1:5 (fraud:benign) to partially correct imbalance while maintaining distributional realism.
Index 112 (Normal): Model Selection: A Multilayer Perceptron (MLP) is selected as the fraud classifier. Architecture: Input(72) -> Dense(256, ReLU) -> Dropout(0.3) -> Dense(128, ReLU) -> Dropout(0.3) -> Dense(64, ReLU) -> Dense(2, Softmax). The MLP is chosen because: (a) its softmax output provides conformal non-conformity scores directly; (b) Opacus handles per-sample gradient clipping automatically for MLP layers; (c) it achieves competitive AUC-ROC of 0.85-0.88 on the pre-processed IEEE-CIS in federated settings, sufficient to demonstrate the improvement from adaptive DP; (d) lower parameter count than transformer models reduces DP noise requirements. Class-weighted cross-entropy loss (weight_fraud = n_benign / n_fraud) is applied in addition to Borderline-SMOTE.
Index 113 (Normal): Federated Training with Hierarchical Adaptive DP: The training loop implements the two novel components. At each round: each client computes conformal non-conformity scores for its mini-batch samples using a locally held calibration set; per-sample DP noise is scaled inversely to the conformal score (high uncertainty = lower noise, low uncertainty = standard noise); clipped and noise-added gradients are computed via Opacus DP-SGD; each client sends its model update and mean uncertainty score to the server; the server computes aggregation weights inversely proportional to client uncertainty and performs weighted FedAvg; the updated global model is broadcast. Privacy budget is tracked using the Renyi DP accountant across all rounds.
Index 114 (Normal): Training and Validation: Training runs for 100 federated communication rounds with N=5-10 simulated clients. Each client holds 80% of its data for training (with Borderline-SMOTE applied), 10% for conformal calibration, and 10% for local evaluation. Global evaluation is performed on a held-out global test set (20% of total data, reserved before partitioning). Five independent runs with different random seeds are performed for each experimental condition to enable Wilcoxon significance testing.
Index 115 (Normal): Testing and Evaluation: See Section 3.3.2 for full evaluation methodology.
Index 116 (Normal): Hyperparameter Tuning: Key hyperparameters include: noise multiplier scaling function (linear, exponential, or sigmoid mapping from conformal score to sigma); clipping norm C (default 1.0, sensitivity analysis at C = 0.5, 1.0, 2.0); number of federated rounds R in {50, 100, 200}; Dirichlet concentration alpha in {0.1, 0.5, 1.0}. Tuning is performed on the validation set before final evaluation on the held-out test set.
Index 117 (Normal): 3.3.2 Evaluation Methodology
Index 118 (Normal): The evaluation framework operates at three levels simultaneously:
Index 119 (Normal): Level 1 — Privacy Validation: The Renyi DP accountant (Google TF Privacy) tracks cumulative (epsilon, delta) at delta=10^-5 across training rounds. Experiments are run at epsilon in {1, 3, 5, 10} to characterise the full privacy-utility tradeoff curve. Membership Inference Attack (LiRA, Carlini et al. 2022) is conducted against the trained model; target AUC of MIA classifier approximately 0.5 (random guessing) indicates strong privacy. Gradient inversion (iDLG) is run on FL without DP and on the proposed system; reconstruction error (PSNR or L2) is reported.
Index 120 (Normal): Level 2 — Utility Validation: Primary metric: AUC-PR (Area Under Precision-Recall Curve) — correct for severely imbalanced data. Secondary metrics: AUC-ROC (for literature comparison), Recall on fraud class, F1-score on fraud class, and Average Precision (AP). Statistical significance is established via Wilcoxon signed-rank test (p < 0.05) across 5 independent runs comparing the proposed system against DP-FedAvg at matched epsilon.
Index 121 (Normal): Level 3 — Uncertainty Calibration Validation: Conformal coverage is verified at target levels (90%, 95%); deviation greater than 2% from the target constitutes a calibration failure requiring investigation. Spearman correlation between conformal non-conformity scores and known fraud labels on borderline cases validates that uncertainty scores are meaningful. Coverage under adaptive DP is compared to coverage under uniform DP to demonstrate that the mechanism preserves calibration while reducing noise on critical samples.
